# Jennifer's - Portfolio
This repository serves as a central portfolio linking to my cybersecurity labs and projects. These labs simulate real-world enterprise environments focusing on Active Directory security, attack simulation, and detection engineering using SIEM tools.

---

## Projects

### 1. [Active Directory SIEM Lab](https://github.com/Jenni-231/Active-Directory-SIEM-Lab)
*Description:*  
Simulated enterprise Active Directory environment with centralized log collection and SIEM integration for security monitoring and threat detection.

*Technologies:*  
Windows Server 2022, Active Directory (ADDS), DNS, Windows 10 Domain Endpoints, Splunk Enterprise, Kali Linux, WinRM Log Collection, Virtual Machines.

---

### 2. [Active Directory Enumeration Detection Lab](https://github.com/Jenni-231/Active-Directory-Enumeration-Detection-Lab)
*Description:*  
Active Directory enumeration lab using offensive tools while analyzing detection opportunities through log monitoring and SIEM analysis.

*Technologies:*  
BloodHound, SharpHound, PowerView, InvisiShell, LDAP, Splunk.

---

### 3. [SOC Privilege Escalation Detection Lab](https://github.com/Jenni-231/SOC-Privilege-Escalation-Detection-Lab)
*Description:*  
Detection engineering lab simulating privilege escalation techniques in Active Directory to analyze Windows telemetry and build Splunk-based detection rules.

*Technologies:*  
PowerUp.ps1, InvisiShell, Jenkins, PowerShell.TCP, GPOddity, SVCFilePath Abuse, NTLMRelayx, Splunk.

---

### 4. [Credential Access & Persistence Detection Lab](https://github.com/Jenni-231/Credential-Access-and-Persistence-Detection-Lab)
*Description:*  
Simulates credential theft and Kerberos ticket forgery attacks while demonstrating detection, monitoring, and remediation strategies in a SOC environment.

*Technologies:*  
Rubeus, SafetyKatz, Invoke-Mimikatz, LSASS, AES / RC4 Kerberos Tickets, Splunk.
